Comece a programar com agentes

O instalador para Windows fica disponível na página de Releases do GitHub.

Baixar o AgenteCode

Instalando pela primeira vez?

  1. Baixe o instalador pelo botão acima e abra o arquivo.
  2. Se o Windows mostrar "O Windows protegeu o computador": clique em Mais informações e depois em Executar assim mesmo. Esse aviso é comum em programas novos que ainda não têm assinatura digital de editor, e não significa que o arquivo tenha algum problema.
  3. Siga o assistente de instalação. Ao final, abra o AgenteCode pelo Menu Iniciar.
Quer conferir a integridade do arquivo? (opcional)

Cada versão publicada traz um código de verificação, o hash SHA-256, na página da Release. Para conferir, abra o PowerShell na pasta do arquivo e rode:

Get-FileHash .\NOME-DO-INSTALADOR.exe -Algorithm SHA256

Compare o resultado com o código da Release. Se forem idênticos, o arquivo é o original, sem alterações.

Ou instale pela linha de comando

PowerShell: baixa o instalador da última Release, mostra o hash SHA-256 e abre o instalador.

$r = (Invoke-RestMethod https://api.github.com/repos/agentecode/agentecode/releases)[0]
$a = $r.assets | Where-Object { $_.name -like '*.exe' } | Select-Object -First 1
Invoke-WebRequest $a.browser_download_url -OutFile $a.name
Get-FileHash $a.name -Algorithm SHA256
Start-Process ".\$($a.name)"

Debian e Ubuntu: baixa o pacote .deb da última Release, mostra o hash e instala.

url=$(curl -s https://api.github.com/repos/agentecode/agentecode/releases | grep -o 'https://[^"]*\.deb' | head -n1)
curl -fLO "$url"
sha256sum "${url##*/}"
sudo apt install "./${url##*/}"
